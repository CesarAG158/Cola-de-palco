Restaurar cópia

As músicas ficam guardadas neste aparelho, neste navegador. Use Salvar cópia para fazer um backup ou levar tudo para outro aparelho.

O seletor de arquivos não abre? Abra esta página direto no Chrome, fora de outro aplicativo, ou use Colar texto.

    Editar música

    Toque na etiqueta à esquerda de cada linha para mudar entre Letra, Acorde e Parte. A linha de acorde aparece na cor de destaque. Toque no texto para corrigir e use os botões da linha para inserir ou excluir.
